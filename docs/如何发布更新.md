# 如何发布更新

本仓库的代码在 `D:\QQ-bot-fork`，机器人实际运行在 `D:\QQ-bot\Koukou-bot`。
**两个目录是分开的**：先在 fork 目录提交推送，再同步到运行目录并重启。

---

## 分支约定（重要）

| 分支 | 用途 |
| --- | --- |
| `dev` | **日常开发都在这里**。你没有推送权限的部分（上游代码）通过它提 PR |
| `main` | 稳定版；一般由上游负责人合并 dev 后更新 |

`发布更新.cmd` 会先推 `origin`（你自己的 fork），再尝试推 `upstream`（原作者仓库）。
推上游失败只会提示，不影响本地和 fork。

## 一、一键发布（推荐）

双击仓库根目录的 **`发布更新.cmd`**：

1. 它会列出你改了哪些文件
2. 问你要提交说明（直接回车 = 「更新」）
3. 自动 `add` → `commit` → `push`

看到 `[4/4] 完成` 就好了。

---

## 二、手动命令（想知道背后做了什么）

在 `D:\QQ-bot-fork` 目录里打开 PowerShell：

```powershell
cd D:\QQ-bot-fork

git status              # 先看改了什么
git add -A              # 把所有改动加入暂存
git commit -m "说明这次改了什么"
git push origin main    # 推到 GitHub
```

三行核心：**add → commit → push**。

---

## 三、推送之后同步到正在运行的机器人

GitHub 更新了，但你本机跑的还是旧代码，要再同步一次：

```powershell
# 1) 复制代码到运行目录（不要覆盖 data / .env / logs）
robocopy D:\QQ-bot-fork\src     D:\QQ-bot\Koukou-bot\src     /MIR
robocopy D:\QQ-bot-fork\scripts D:\QQ-bot\Koukou-bot\scripts /MIR

# 2) 重启机器人
schtasks /end /tn KoukouQQBot
schtasks /run /tn KoukouQQBot
```

然后打开 <http://127.0.0.1:8787> 确认控制台正常。

> `data\`、`.env`、`logs\`、`data\personas\` 是**本机数据**，同步时不要动它们。

---

## 四、从上游更新（原作者发了新版本）

```powershell
cd D:\QQ-bot-fork
git fetch upstream
git merge --ff-only upstream/main
git push origin main
```

如果 `--ff-only` 报错（说明两边都改过同一个文件），改用：

```powershell
git merge upstream/main
```

手动解决冲突后再 `git add -A`、`git commit`、`git push`。

---

## 五、常见问题

**Q：push 报 `Permission denied (publickey)`**
SSH 密钥没加或丢了。重新生成并加到 GitHub：

```powershell
ssh-keygen -t ed25519 -C "yemuxi520@github" -f "$env:USERPROFILE\.ssh\id_ed25519" -N ""
type "$env:USERPROFILE\.ssh\id_ed25519.pub"
```

把输出的那行贴到 <https://github.com/settings/ssh/new>。

**Q：push 报 `rejected` / `non-fast-forward`**
远程有你本地没有的提交，先拉再推：

```powershell
git pull --rebase origin main
git push origin main
```

**Q：提交里出现了密钥或聊天记录？**
检查 `.gitignore` 是否漏了。已经提交的敏感文件要从历史里删掉，不要只删文件——先找我处理。

**Q：改错了想撤销上一次提交（还没推送）**

```powershell
git reset --soft HEAD~1   # 撤销提交，改动还在
```

## 七、控制台打不开 / 关了浏览器怎么办

**桌面「QQ机器人」→ 点主按钮**即可：

- 机器人已经在跑 → **直接在浏览器打开** <http://127.0.0.1:8787>（不到 0.2 秒）
- 机器人没跑 → 先触发启动，**启动脚本会自己打开控制台**，不用再点第二次

命令行也可以：`D:\QQ-bot\打开控制台.cmd`。

## 八、同步并重启（本地专用脚本）

`D:\QQ-bot\同步并重启.cmd`（**不在仓库里**，因为路径是本机专用的）：

1. 把 `D:\QQ-bot-fork\src` 和 `scripts` 镜像同步到 `D:\QQ-bot\Koukou-bot`
2. 结束再用计划任务重启机器人
3. 等 8787 就绪，并自动打开控制台

桌面快捷方式「同步并重启」就是它。`data`、`.env`、`logs` 不会被动到。

想在自己别的机器上做一个，把脚本里的三个变量改掉即可：

```bat
set "SRC=<仓库目录>"
set "DST=<运行目录>"
set "TASK=<计划任务名>"
```

## 九、桌面统一入口（推荐）

桌面上现在只有一个图标 **「QQ机器人」**（`D:\QQ-bot\QQ机器人.cmd`），双击出菜单：

```
1. 打开控制台          （没运行会自动拉起）
2. 同步代码并重启      （改完代码 / 发版后用）
3. 完全启动            （含 LLBot，冷启动用）
4. 查看运行状态        （端口 / 任务状态 / 最近日志）
5. 发布更新到 GitHub   （提交 + 推送）
0. 退出
```

也可以带参数直接调用，方便做别的快捷方式：

```powershell
D:\QQ-bot\QQ机器人.cmd open      # 打开控制台
D:\QQ-bot\QQ机器人.cmd sync      # 同步并重启
D:\QQ-bot\QQ机器人.cmd status    # 看状态
D:\QQ-bot\QQ机器人.cmd publish   # 发布到 GitHub
```

> 这个脚本里有本机路径（`D:\QQ-bot-fork`），所以不放进仓库，只放本机。

## 十、图形控制面板（按钮，不用输入）

双击桌面 **「QQ机器人」** 打开按钮窗口（`D:\QQ-bot\menu.ps1`）：

```
QQ 机器人
控制台 8787 ： 运行中
OneBot 3001 ： 运行中
计划任务    ： Running

[ 打开控制台界面 ]        ← 运行中：直接开网址
[ 同步代码并重启 ]
[ 刷新运行状态 ]
[ 发布更新到 GitHub ]
```

- 没运行的时候主按钮会变成「**启动机器人（含 LLBot）**」，点一下触发启动
- 启动完成后控制台由启动脚本自动弹出，**不会再开第二个**
- 状态每 3 秒自动刷新；按钮点击后立即响应（没有阻塞等待）
