# Python 后端迁移

## 范围与状态

目标：完整迁移机器人后端与插件系统，保留现有网页 HTML/CSS/JavaScript。迁移从 main 的 `d336b09` 开始，在 `py` 分支和独立工作目录进行，不切换正式实例，不自动合并回 main。

**当前为首批原生实现，尚未实现完整功能等价，也未达到生产切换标准。** 测试和 GitHub 检查通过，只证明已实现部分满足现有测试，不能解释为所有功能已经迁移。

旧后端保留在 `src/` 作为行为参照；Python 代码在 `python/koukou/`，运行时不借助 Node 执行旧业务逻辑。保留旧代码不代表对应功能已由 Python 承接。

6. 文件打包/分卷、插件附件与聊天卡片发送、超时不重发、自动撤回完整移植。
7. 控制台剩余API、QQ登录、更新、诊断、指标、备份和Windows启动/停止/重启方式完整移植。

## 安装与预览

需要Python 3.11以上，单独虚拟环境安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e .
.\.venv\Scripts\python -m koukou migration
.\.venv\Scripts\python -m koukou preview --port 8790
```

控制台预览只绑定127.0.0.1，顶部显示迁移提示。默认使用当前分支目录的`data-python`，不会接管main的8788端口或QQ连接。预览支持的写操作仅适用于开发数据，不能保证对全部旧数据格式的兼容；不要传入正式数据目录。

## 新建插件

```powershell
.\.venv\Scripts\python -m koukou plugin new hello --description "简单问候"
.\.venv\Scripts\python -m koukou plugin run hello 群友
```

生成`plugins/python/hello.py`，保持顶部元数据，编辑函数即可：

```python
from koukou.plugin import plugin

@plugin.command
def handle(args: list[str]) -> str:
    return "你好，" + (" ".join(args) or "大家")

if __name__ == "__main__":
    plugin.run()
```

可使用`async def`，需要结构化输出时返回`Result(text=..., images=[...], files=[...])`。运行器保持兼容独立脚本的stdout、`@@CARD@@`和`@@FILE@@`解码。原生投递已通过模拟OneBot的文字、图片、聊天记录和文件测试，尚未进行真实QQ验收。新SDK依赖此Python包，不应把SDK插件直接放进尚未安装该包的main实例。

## 统一指令入口

Python插件以普通指令注册到指令中心，与`/help`和`/Q`并列，例如`/calc 1+2`、`/jm 帮助`；控制台修改调用名后，也可使用`/计算 1+2`。私聊可直接输入，群聊仍需@机器人或可靠引用机器人。旧`/py 名称 参数`仅作兼容入口，不再作为帮助或新模板的主用法。

插件共享内置指令卡片的开关、适用范围和管理员权限设置；默认管理权限保持原状。源码声明`# admin: true`的插件不能通过控制台取消管理员限制。保留`/help`、`/Q`等内置名称；新建和重命名拒绝与内置、自定义斜杠指令及其他插件冲突，已有冲突会停止注册而不任意选择其中一个。源码编辑区保留为高级管理入口。

这只完成了统一命名和现有插件路由，不代表完整迁移已完成；原生正式QQ入口仍受迁移验收限制。

## 群管理与附件迁移进展

新增原生群管理意图识别、对象证据核对和执行管线：禁言/解禁、全员禁言、本人或授权管理者引用撤回，以及白名单群请求拍一拍。管理功能默认关闭，需显式配置群范围；管理者须为群主，或同时满足控制台管理员与实际群管理员身份。禁言/撤回要求机器人具有实际QQ管理权限，每次执行前重新读取身份。澄清仅接同一请求者在本群两分钟内的第一条补充，连接变化后丢弃待处理上下文。

时长支持中文、英文单位与有限数学式，通过29组JS/Python行为对照；仅在最终结果向上取整，超过30天拒绝执行。模型不能自造目标或时长。动作提交前持久化去重；QQ回执不明时告知核对，不自动重试。此机制优先避免重复执行，不能保证跨进程崩溃后恰好执行一次。

插件结果在发送前检查本地文件、图片路径和聊天记录节点；文件请求单次允许等待600秒，只有明确不支持文件消息段时才改用上传API。回执不明会停止后续部分；有消息ID的文件可由清理器撤回，上传API没有消息ID时明确标记不能自动撤回。清理器已离线验证，正式运行的调度仍待接入；文件打包/分卷和现有全部插件行为仍待验证。拍一拍的人格回复与通知流程也尚未完整移植。

当前离线回归46项，另有192组回复决策、10组复读指纹和29组时长对照。群总结、表情包、人格完整迁移及剩余控制台接口仍是替换main前的必要条件；预览限制继续保留。
