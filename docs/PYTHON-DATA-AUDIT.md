# Python 迁移的数据只读检查

`koukou.migration_audit.audit_data(data_dir, persona_dir=None, env_file=None)`
只读取明确传入的目录和文件，不连接 QQ 或模型，不构造机器人服务，也不迁移、
隔离、修复或覆盖源文件。未提供的 `.env` 和外部人格目录不会被自动查找。

在已安装 Python 迁移包的环境中，可检查一个明确选择的离线数据副本：

```powershell
python -m koukou audit-data --data-dir "D:\BotMigration\data-copy"
```

若该副本使用独立的人格目录或需要核对所选人格，可显式传入对应副本路径：

```powershell
python -m koukou audit-data --data-dir "D:\BotMigration\data-copy" --persona-dir "D:\BotMigration\personas-copy" --source-env "D:\BotMigration\instance-copy.env"
```

这些参数不会写入源配置，也不会按源配置里的协议地址连接 QQ。退出码 `0`
表示结构检查通过，`1` 表示发现阻止兼容性通过的问题；警告仍须查看。

检查覆盖近期和长期记忆、清理边界、人格记忆分区、会话人格设置、指令权限与
自定义指令、识图接口配置、静态问候语库、人格表情包库、黑名单、图片缓存、
长期原文和每日聊天 JSONL。图片会核对实际文件的 SHA-256、格式和大小。
检测到未完成的记忆事务或还原任务时，要求先按原有恢复流程处理。
离线回归另用原 JavaScript 写入器生成临时夹具，再验证 Python 审计接受这些
真实写出格式；CLI 回归同时检查源文件不变、UTF-8 输出与错误退出码。

输出只含常量错误代码、类别、计数和整个已检查文件集合的指纹，不包含会话号、
人格名、聊天正文、标签、描述、接口地址、凭据或本机绝对路径。

- `compatible: true` 只表示这次已检查的数据结构通过；`ready` 始终为 `false`，
  不表示运行验收通过，也不授权切换生产。
- `errors` 阻止兼容性通过；`warnings` 表示仍需人工检查的项目，例如旧图库尚未
  记录所属人格、已满图库尚未落盘暂停标记、可以重新下载的缓存图片缺失。
- `fingerprint` 可比较同样相对结构的离线副本。它不是备份，不保证运行中的
  文件集合具有跨文件事务一致性。检查过程中检测到文件变化会报错；仍应在
  正式迁移时先停止写入，再创建并验证完整备份与回滚副本。

单个 JSON 或 JSONL 超过 32 MiB，或检查文件超过 20,000 个时，会明确报出
检查不完整，不会只读取尾部然后把整份档案标为通过。备份目录、临时日志、
插件代码和外部路径不在本检查的完整验收范围内，需要各自验证。

这些限制属于离线审计的资源保护，不改变机器人群总结的模型上下文、输出长度
或整份任务等待方式。
